📤 Test 413 Payload Too Large

Upload a file larger than 100MB to trigger the 413 error.

💡 How to test 413:
1. Create a large file: dd if=/dev/zero of=/tmp/large.bin bs=1M count=150
2. Upload that file using this form
3. nginx will return 413 Payload Too Large
4. nginx will serve /errors/413.html custom error page
